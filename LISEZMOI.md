# Atelier procédure civile : mise à jour

Tous les fichiers de cette archive se placent à la racine du dépôt GitHub, sans dossier.

1. Décompressez l'archive.
2. Dans le dépôt, onglet « Code » : « Add file », puis « Upload files ».
3. Faites glisser tous les fichiers ; ceux de même nom remplacent les anciens.
4. Cliquez sur « Commit changes », puis attendez la coche verte dans l'onglet « Actions ».
5. Sur le téléphone, fermez puis rouvrez l'application pour charger la nouvelle version.

Ne déposez jamais dans ce dépôt public de thèse, de manuel ou de cours.
